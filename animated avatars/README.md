# Animated avatars

## Gorilla avatar (royal purple on lime green, face close-up)
- gorilla-avatar.gif       animated, 512x512, 36 frames at 60 ms, loops forever
- gorilla-avatar-250.png   static 250x250 fallback (Google profile photos show a still)
- gorilla-avatar-still.png static 512x512 first frame
- gorilla.py               generates all of the above (run: python3 gorilla.py)
- gorilla-page.html        source of the shareable web page

Web page: https://claude.ai/artifact/HMaAbvifnAing1fGQr28Si (private until shared)

Notes
- Gmail and Google Account profile photos only show a still image.
- GIFs play in the body of an email but not in the Gmail app attachment preview.
- Look settings live in gorilla.py: colors (dark/mid/face/light, background),
  zoom crop (last line of frame()), animation timing (N, duration).
